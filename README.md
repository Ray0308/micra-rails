# マイクラレールズ / Micra Rails

スマートフォン・タブレット向けの静的HTMLゲーム試作。ビルド・外部ライブラリ・通信・アカウント不要。

## 遊び方

1. 空きマスに隣接するパネルをタップ、または空きマス方向へスワイプしてレールを準備。
2. スタートするとスティーブが左上から右下の駅へ自動で進む。
3. 通過したレールパネルは固定。通常パネルには再進入できない。十字は直進のみ、縦横各1回使える。
4. 約5.5秒後からクリーパーが足あとを追跡。追いつくと約0.95秒の点滅後に爆発。猶予中に離れれば解除。
5. 道がつながっていないとスティーブは待機。パネルを動かして脱出させる。

現段階では出発地点は固定。3つの盤面は同じ基本経路の配置違いで、ゲーム性を確認するためのもの。自由配置、追加ステージ、効果音の作り込みは今後の対象。

## 起動

このフォルダで `python3 -m http.server 8080` を実行し、ブラウザで http://localhost:8080 を開く。ES Modulesを使用するため、HTMLの直接ファイル起動では動作しない場合があります。

## 画像素材を差し替える

次のPNGを `assets/` に置くと起動時に自動で読み込みます。画像なしでもCSSの仮キャラクターで遊べます。

| ファイル | 内容 | 推奨 |
| --- | --- | --- |
| `assets/steve.png` | スティーブ | 透過PNG、正方形、64〜256px |
| `assets/creeper.png` | クリーパー | 透過PNG、正方形、64〜256px |
| `assets/house.png` | ゴールの駅 | 透過PNG、正方形、64〜256px |

キャラは正面または見下ろしで、余白を少なめに。アニメーションシートは現段階では不要。

## GitHub Pages

1. GitHubで新しい公開リポジトリを作成。
2. このフォルダの中身をリポジトリ直下にアップロード。
3. Settings → Pages → Build and deployment → Deploy from a branch を選択。
4. `main` と `/(root)` を選び、Save。
5. デプロイ完了後、表示されたURLをスマホなどで開く。

`.nojekyll` を含めてそのまま配信できます。パスはすべて相対指定で、プロジェクト用Pagesにも対応。URLのアクセス制限はありません。

## 確認

`node --test tests/engine.test.mjs`

スライド制約、通過済みパネル、十字の再横断、追跡、全盤面の解答経路を検証。

## バージョン更新ルール

現在のバージョンは **0.1.1**。画面右上に全画面共通で表示。

ユーザー向けの更新・公開1回につき末尾を1増やす（ファイルごとのコミット数では数えない）。各桁は0〜9、10になると左の桁へ繰り上げる。

例: `0.1.0 → 0.1.1 → … → 0.1.9 → 0.2.0`、`0.9.9 → 1.0.0`。

更新時は index.html の version-badge の表示・aria-label、CSSとJSのクエリ文字列を同じバージョンに揃え、この現在バージョンも更新する。
