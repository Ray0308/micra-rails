# マイクラレールズ / Micra Rails

スマートフォン・タブレット向けの静的HTMLゲーム試作。ビルド・外部ライブラリ・通信・アカウント不要。

## 遊び方

1. 「はじめる」でワールドを選び、「出発」を押す。出発前はパネルを動かせない。
2. 走行開始後、選んだワールドの操作でレールをつなぐ。スティーブを左上から右下の駅へ誘導する。
3. 通過したレールパネルは固定。走行中の接続先は進入中として一時的に移動不可。通常パネルには再進入できない。十字は直進のみ、縦横各1回使える。
4. 約5.5秒後からクリーパーが歩いて足あとを追跡。約5.5秒で出現し、近づくと3秒の点滅後に爆発。猶予中に離れれば解除。
5. 道がつながっていないとスティーブは待機。パネルを動かして脱出させる。

出発地点は左上、ゴールは右下。坑道はランダム生成し、クリアのたびに番号が1ずつ進む。同じ坑道のやり直し・再読み込みでは同じ盤面を再開する。

## 起動

このフォルダで `python3 -m http.server 8080` を実行し、ブラウザで http://localhost:8080 を開く。ES Modulesを使用するため、HTMLの直接ファイル起動では動作しない場合があります。

## 画像素材を差し替える

次の画像を `assets/` に置くと起動時に自動で読み込みます。画像なしでもCSSの仮キャラクターで遊べます。

## GitHub Pages

1. GitHubで新しい公開リポジトリを作成。
2. このフォルダの中身をリポジトリ直下にアップロード。
3. Settings → Pages → Build and deployment → Deploy from a branch を選択。
4. `main` と `/(root)` を選び、Save。
5. デプロイ完了後、表示されたURLをスマホなどで開く。

`.nojekyll` を含めてそのまま配信できます。パスはすべて相対指定で、プロジェクト用Pagesにも対応。URLのアクセス制限はありません。

## v0.1.6 — キャラ図鑑とブロック破壊報酬

図鑑の収集・カテゴリ・詳細・キラ・再会回数・端末保存は、同じ作者の [きょうりゅうのしま](https://github.com/Ray0308/kyoryu-island-play) の図鑑機能を参考に、このゲーム専用のモジュールへ移植。

- クリア → 鉱石ブロック → 5回のタップでひびが増える → ブロックが砕けてカードが出る。
- 初期はスティーブ1枚。通常キャラ12種類＋ボス2種類、4カテゴリ。画像未提供のキャラはブロック形の仮表示。
- 最初の3報酬は未発見の通常キャラを優先。重複が2回続いた場合も次は未発見を優先（残りがある場合）。通常12種類のうち10種類を集めると初めてのボスを保証。それ以外のボス確率は2%、キラは別に5%。
- 通常・キラは同じ図鑑の枠で管理。キラの有無と合計枚数を別に記録する。
- 保存キーは `micra-rails.collection.v1`。恐竜ゲームの保存領域とは分離。保存はその端末・ブラウザ内。
- 抽選済みカード、ひびの段階、表示中のカードも保存。ページを再読み込みしても同じ報酬を再開し、5回目のタップで1回だけ登録する。
- 「次の坑道へ」で次ステージへ。03の次は01。タイトルに戻っても未破壊ブロックは次の「はじめる」で再開。

### キャラ画像の差し替え

`catalog-data.mjs` の各キャラの `id` は変更しない。画像を下の名前で置き、該当キャラの `image` にパスを設定する。これにより収集済みデータを維持できる。透過PNG/WebP・全身が切れない画像を推奨。新しい画像を反映するときも通常のバージョン更新を行う。

| カテゴリ | キャラID（ファイル名） |
| --- | --- |
| なかま | `steve` / `alex` / `villager` / `iron-golem` |
| どうぶつ | `pig` / `cow` / `wolf` / `cat` |
| モンスター | `creeper` / `zombie` / `skeleton` / `enderman` |
| ボス | `ender-dragon` / `wither` |

例: `assets/cards/alex.png` を置き、アレックスの定義に `image:'assets/cards/alex.png'` を追加。現在のスティーブ・クリーパーはゲーム中のPNGを仮利用。

## v0.2.3 — オプションと音量

タイトルの「終了」を「オプション」に置換。サウンドON/OFF、BGMと効果音それぞれ0〜100のスライダー、完了でタイトルへ戻る構成。

音量は `micra-rails.audio.v1` に保存。初期は以前の動作に合わせサウンドOFF、BGM50・効果音50。ゲーム右上の音ボタンも同じ設定を切り替える。BGMと効果音は別のGainNodeで制御し、0でミュート。サウンドOFFは読み上げも含めて停止。タブを隠すと音も停止し、初回の音声再生はユーザー操作後に開始。

BGMファイルは未提供のため、Web Audioによる静かなオリジナルの仮メロディを実装。録音済みBGMへは `audio.mjs` の音源部分を差し替える。設定画面は音源に依存しない。

音量・保存・ミュート・音の経路・バックグラウンド停止の確認は `node tests/audio.test.mjs`。

## v0.2.4 — ゲーム画面のレイアウト整理

## v0.2.5 — ランダム坑道と連続進行

ステージ選択を削除。坑道番号は01から始まり、クリアで1ずつ増えて03で戻らない。`micra-rails.journey.v1` に番号と盤面シードを保存し、やり直し・再読み込みは同じ盤面、次のクリアで新しい盤面になる。

4×4盤面に6〜10区間のつながるルートを作成してから、隣接スライドで崩す。最初の3枚とゴールは崩さず、崩した操作の逆順で解けることを実際のルールで確認。何も動かさずにゴールできる盤面は除外。最初の走行中にも操作時間を確保。キャラの速度は変更しない。

報酬の坑道番号の保存も3ステージ制限を外し、以前の図鑑・音量・途中の採掘状態を維持。クリア時と報酬後に同じ番号を処理しても二重に進まない。

検証: `node tests/generator.test.mjs` で500シードの生成盤面を出発後250ms間隔の操作でクリアできることを確認。`node tests/journey.test.mjs` で連続進行・保存・高い坑道番号の報酬復元を確認。

## v0.2.6 — クリーパーの点火と速度

クリーパーを1マス1.5秒から1.7秒へ減速（トロッコは1.9秒のまま）。接触で立ち止まってシュー音・点滅を開始し、3秒後に爆発。点火中に距離を離すと解除し、追跡を再開。点滅は爆発が近づくほど速くなる。シュー音は効果音の音量・サウンドOFFに従い、離脱・一時停止・画面切替・決着時に停止。

## v0.2.7 — 図鑑の確認用開放

ユーザー指定により全88種類の通常・キラカードを最低1枚ずつ開放。既存の通常枚数・キラ枚数は減らさず、抽選回数・坑道進行・途中の採掘には影響しない。一度だけ付与する印を保存するため、再読み込みで枚数は増えない。

一時開放フラグは `catalog-ui.mjs` の `REVIEW_UNLOCK_ALL`。付与前の図鑑全体は `micra-rails.collection.review-backup.v0.2.7` に保存してあり、後で通常進行へ戻すときに使える。音量設定は変更しない。読み上げ確認はサウンドON、効果音を0より上に設定して行う。

## v0.3.1 — スティーブの停車／発車

出発ボタンを、走行開始後は「停車／発車」の切替ボタンとして利用。停車中もレールをスライド可能で、スティーブが進んで新たなパネルを固定するのを止められる。クリーパーの移動・点火・爆発タイマーは継続する。既存の一時停止は両キャラ・タイマーを止め、パネル操作も止める別機能として維持。

走行途中で停車しても位置や進入予定レールを保持し、発車時は同じ位置から連続して再開。停止時間を移動量に加算しない。やり直し時は停車状態を解除。出発前のパネル操作は禁止したまま。

## v0.3.1 ワールド

| ワールド | 操作 | キラ率 | ボス抽選率 |
